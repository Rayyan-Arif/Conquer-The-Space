# 👾 Conquer The Space

A fast-paced 2D arcade shooter built with Godot.

Aliens are roaming through space, and your goal is simple: **click and destroy as many as possible before the 60-second timer expires**. Every alien you eliminate increases your score, so stay focused and keep shooting until time runs out.

## 🎮 Gameplay

* Aliens move around the screen.
* Left-click an alien to destroy it.
* Earn points for every alien eliminated.
* The game ends after 60 seconds.
* View your final score at the end of the round.

## ✨ Features

* One-minute arcade challenge
* Simple click-to-shoot gameplay
* Score tracking
* Fast-paced action
* Built with Godot Engine

## 🖱️ Controls

| Action      | Control          |
| ----------- | ---------------- |
| Shoot Alien | Left Mouse Click |
